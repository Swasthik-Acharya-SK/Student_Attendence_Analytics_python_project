# Student Attendance Analytics

## About the Project
Student Attendance Analytics is a Python project that uses Pandas and Jupyter Notebook to analyze student attendance data and identify attendance patterns.

## Objectives
- Analyze student attendance records.
- Generate attendance summaries.
- Identify students who may require attendance follow-up.
- Present useful insights from attendance data.

## Technologies Used
- Python
- Pandas
- Jupyter Notebook
- CSV and Excel

## Project Notebook
`Project_Student Attendance Analytics with Pandas.ipynb`

## How to Run
1. Clone this repository.
2. Install the required libraries:
   `pip install pandas jupyter openpyxl`
3. Start Jupyter Notebook:
   `jupyter notebook`
4. Open the project notebook and run the cells.
